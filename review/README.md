# Site check

Generated by `python -m stp.cli review` from the ranked sites (corrected land cover, original weights, `>= 8` rule).

- `site_check.csv`: one row per site. Open it in Excel or Google Sheets and fill the last four columns.
- `sites.kml`: the site outlines. Open in Google Earth Pro (File > Open), or import it as a KML file in Google Earth web's Projects panel, to see each site's exact shape rather than a single point.

## What to check

For each site, open the `google_maps` link (satellite view, zoom 18). If Google's imagery is old or cloudy, try `bing_aerial`. Compare with the outline in `sites.kml`. Judge the land **inside the outline**, as it looks today.

## Columns to fill

| Column | Values |
|---|---|
| `observed_cover` | `bare` (open, unused ground), `farmland` (fields, ploughed or fallow), `scrub` (grass, bushes, scattered trees), `built` (buildings, paved, under construction), `water`, `other` |
| `usable_for_stp` | `yes`, `no`, `unsure`: could a small treatment plant plausibly go here (open land, not obviously in use)? |
| `confidence` | `high`, `medium`, `low`: how clear the imagery is |
| `notes` | Anything notable, e.g. "brick kiln", "quarry", "new houses on the east half", "imagery dated 2019" |

## Useful context columns

- `robust`: selected in at least 75% of the weight-perturbation draws (`persistence` is the exact share).
- `in_original_46`: overlaps one of the 46 sites from the original QGIS analysis; `False` means the land-cover correction added it.
- `drivable_last_mile_m`: straight-line distance from the site to the nearest drivable road junction.

If time is short, check the 20 `robust = True` sites first.
